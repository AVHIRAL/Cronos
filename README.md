# Cronos

https://www.avhiral.com/download/Cronos_HTTP4_Protocole.zip

Cronos HTTP4 est un environnement de navigation et d’analyse réseau développé par AVHIRAL. Il réunit un navigateur Windows, un agent de connexion et des outils permettant de mieux comprendre les échanges entre le navigateur et les services consultés.

Son protocole applicatif Cronos CRN4 permet des communications authentifiées avec les services natifs compatibles, accessibles par des adresses httavhs://. La navigation sur les sites publics utilise HTTPS à travers le transport configuré : tunnel, relais ou proxy.

Le système NoDataLeak propose des restrictions destinées à limiter certaines informations transmises par le navigateur : suivi connu, référent, communications WebRTC et stockage persistant selon le mode choisi.

Cronos intègre également LiveStream, une console de diagnostic, l’analyse XDream, l’inspection du contenu reçu et du DOM, ainsi que des outils développeur. Onglets, favoris personnalisables, filtrage publicitaire et vidéo flottante complètent l’expérience.

Une même interface pour naviguer, observer les échanges et maîtriser ses paramètres de confidentialité.
